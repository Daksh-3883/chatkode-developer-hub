# ChatKode Brand and Motion Refinement

## Goal
Preserve the approved page structure and content while making the experience unmistakably ChatKode: technical, energetic, collaborative, and derived directly from the supplied logo.

## What will change
- Replace the current teal-led palette with a restrained logo-derived system: deep navy surfaces, electric blue interaction, cyan technical signals, green activation/success, gold mathematics/logic, and soft cyan-white text.
- Place the supplied dark logo in the existing wordmark locations and create a padded square favicon from the same source.
- Refine the hero atmosphere with angular circuit paths, connected nodes, and a staged activation sequence; retain the current two-column layout and wording.
- Change the hero code demo from slow perpetual typing to a controlled grouped reveal with brief line focus and a settled final state.
- Give existing sections meaningful active/completed states as they enter and leave the reading window, without changing their structure.
- Animate the existing pipeline and algorithm diagram as information flow: blue/cyan connections, green completed stages, and gold decision points.
- Make mathematics use restrained gold emphasis, coding use blue/cyan, and algorithms use green progress with blue connections.
- Refine buttons, links, tabs, panels, and cards with subtle border, glow, translation, and press feedback—never full-bright hover floods.
- Make the final call-to-action visually converge and settle around the strongest electric-blue brand signal.

## Mobile and accessibility
- Simplify path density and simultaneous motion on smaller screens while keeping the logo, color roles, and story visible.
- Prevent horizontal page overflow while preserving intentional scroll inside code/diagram surfaces.
- Respect reduced-motion preferences by disabling parallax, continuous drift, path travel, and staged delays while showing every final state immediately.

## Technical approach
- Add semantic brand tokens and lightweight CSS keyframes in the existing global stylesheet.
- Extend the existing IntersectionObserver utilities for active section state; no animation dependency will be added.
- Use transform, opacity, stroke drawing, and CSS custom properties for smooth animation.
- Update only the existing shared primitives, hero/code surfaces, pipeline, mathematics, algorithms, and final CTA where needed.
- Verify navigation, buttons, console output, overflow, desktop, mobile, and reduced-motion behavior in the browser.
